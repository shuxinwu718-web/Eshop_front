# 商城个性化设置（背景色 + 主题色/暗色/灰/色弱）

## Context

用户商城「我的」页缺少个性化设置，而商家中心/管理后台已有完善的个性化设置（主题色/暗色/灰色/色弱/侧边栏/布局），基于 Pinia `useSettingsStore`（localStorage 持久化）+ `utils/theme.ts`（写 `--el-color-*` CSS 变量、html.dark class）全局生效、零后端依赖。

目标：把该套机制的**纯视觉项**迁移给用户商城，并新增「商城专属背景色」预设（默认/暖米/浅蓝/浅粉）。**剔除布局类项**（侧边栏配色、tagsView、布局切换等管理端特有）。用户已确认方案 B。

## 现状关键结论

- 商城布局背景写死 `#f5f6f8`（ShopLayout.vue `.shop-layout`）；无商城专用背景变量
- 商城页面卡片底色大多 `var(--el-bg-color)`（可随暗色变），少量硬编码渐变（秒杀页、优惠券卡片）
- 全局变量 `--page-bg`、`--price-color` 已存在（_variables.scss），新增变量无冲突
- App.vue 实例化 settingsStore 即触发 immediate watch 应用主题，初始化零额外代码
- 商城「我的」两页面：移动端 MyCenter.vue（功能 cell 列表）+ 桌面 shop/center/index.vue（el-menu + 右侧面板）

## 实施步骤

### 1. 状态与工具
- **src/settings.ts**：`defaults` 加 `shopBgColor: "default"`；导出 `shopBgPresets`（4 组 `{ value, label, bg, card }`）：
  - default：bg `#f5f6f8` / card `#ffffff`
  - 暖米 warm：bg `#faf5ec` / card `#fffdf7`
  - 浅蓝 blue：bg `#eef4fb` / card `#ffffff`
  - 浅粉 pink：bg `#fdf0f3` / card `#ffffff`
- **src/store/modules/settings.ts**：新增 `shopBgColor = useStorage(常量, "default")`；`watch(shopBgColor, v => applyShopBg(findPreset(v)), { immediate: true })`；`resetSettings` 一并重置
- **src/constants/index.ts**：加 `SHOP_BG_COLOR` 存储 key 常量（沿用现有 `${APP_PREFIX}:ui:...` 风格）
- **src/utils/theme.ts**：新增 `applyShopBg(preset)`，对 `document.documentElement` setProperty `--shop-bg` / `--shop-card-bg`

### 2. CSS 变量与布局
- **src/styles/_variables.scss**：`:root` 加 `--shop-bg: #f5f6f8; --shop-card-bg: #ffffff;`；`html.dark` 内覆盖为 `var(--el-bg-color-page)` / `var(--el-bg-color)`（暗色下忽略浅色预设）
- **src/layouts/ShopLayout.vue**：`.shop-layout` 根背景 `#f5f6f8` → `var(--shop-bg, #f5f6f8)`；暗色段保留

### 3. 设置抽屉组件（新建）
- **src/components/ShopSettingsDrawer/index.vue**（放 components，商城专用）
- el-drawer，`size="isMobile ? '100%' : '380'"`（useIsMobile）
- 内容：主题色 el-color-picker（`:predefine=themeColorPresets`）、暗色 el-switch、商城背景色 4 色块（显示 preset.bg 圆块，选中加主色边框）、灰色模式、色弱模式、footer「恢复默认」
- 全部直接绑定 `useSettingsStore`

### 4. 入口
- **src/views/shop/member/MyCenter.vue**：功能列表加「个性化设置」cell（图标 ⚙/🎨），点击打开抽屉
- **src/views/shop/center/index.vue**：el-menu 加 `index="settings"` 项 + `handleMenuSelect` 分支打开抽屉（不新增 v-show 面板，纯打开组件）

### 5. 页面硬编码适配（少量）
- **src/views/shop/seckill/index.vue**（L363-379 附近）渐变起色 `#fff5f5`/`#f0f9ff` → `var(--shop-bg)`
- **src/views/shop/coupon/components/CouponCardList/index.vue**（L164/175 附近）渐变起色 → `var(--shop-bg)`、终止 → `var(--shop-card-bg)`
- 其余 `var(--el-bg-color)` 卡片与继承背景的页面不动；shop/center 的 dark 硬编码（#161b22）为暗色专属，不动

### 6. 复用点
- 全部逻辑复用现有 `useSettingsStore` + `theme.ts`，不新写主题机制
- 与商家/管理端共用同一 store（全局偏好，跨端一致，符合预期）

## 验证

1. `npm run build` 通过
2. 手动：移动端「我的」→ 个性化设置 / 桌面个人中心菜单 → 设置，逐项切换：
   - 背景色 4 组切换 → 整站背景/秒杀页/优惠券卡渐变随之变
   - 主题色 → 主按钮/链接色变
   - 暗色 → 整站暗色，背景回退 el 变量
   - 灰色/色弱开关、恢复默认
3. 刷新浏览器验证 localStorage 持久化
4. 进管理后台确认其 LayoutSettings 不受影响
