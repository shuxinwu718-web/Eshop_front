### 五、架构模式
- 架构风格 : 前后端分离的单体应用 (Monolithic)
- 后端架构 : 经典三层架构 (Controller -> Service -> Mapper/Repository)
- 前端架构 : SPA单页应用，基于 Vue Router 的前端路由
- 认证方式 : JWT Token (Bearer 方式)
- 数据库访问 : MyBatis-Plus (自动填充、逻辑删除、分页)
- 搜索 : Elasticsearch (商品索引 product_index )
- 缓存 : Redis (验证码、在线用户、秒杀库存预热)
- 实时推送 : SSE (Server-Sent Events，用于在线人数和字典同步)
- 角色权限 : 三种角色 -- USER（普通用户）、MERCHANT（商家）、ADMIN（管理员）
- 部署方案 : Docker Compose (MySQL + Redis + Elasticsearch + App)

## 后端接口兼容性说明
两个课题的改进方案中， 约70%的接口可以直接复用现有后端API （商品、用户、订单、购物车、收藏、评论等），需要新增的接口主要集中在：

现有后端项目的架构（Spring Boot 3 + MyBatis-Plus + Redis + ES）完全支持这些扩展，只需在现有 e-shop 项目中新增模块即可。
