## 1. 项目总览

本项目为 **B2B2C 电商购物系统**（毕业设计课题：基于 SpringBoot + Vue3 的 B2B2C 电商购物系统），前后端分离的单体应用，包含三种角色：普通用户（USER）、商家（MERCHANT）、平台管理员（ADMIN）。

| 子项目 | 路径 | 技术栈 | 端口 |
|--------|------|--------|------|
| 前端 Eshop | `C:\Users\admin\Desktop\项目\电商系统\Eshop` | Vue 3.5 + TypeScript + Vite 8 + Element Plus 2.13 + Pinia + vue-i18n | 3000 |
| 后端 e-shop | `e:\idea_workspase\e-shop` | Spring Boot 3.2.2 + MyBatis-Plus 3.5.6 + Spring Security + JWT + Redis + ES + MySQL | 8080 |
| AI 客服服务 | `E:\Python-wordkspace\ai-customer-service` | Python + FastAPI + DashScope（通义千问 qwen-turbo，Function Calling Agent） | 5000 |

### 1.1 总体架构

```
┌─────────────────────────────────────────────────────────────┐
│  客户端层：普通用户浏览器 / 商家浏览器 / 管理员浏览器            │
└──────────────────────────┬──────────────────────────────────┘
                           │ HTTP / Axios（/dev-api 代理 → :8080/api）
┌──────────────────────────▼──────────────────────────────────┐
│  前端应用层（Vue3 SPA）                                       │
│   ├─ shop/      商城前台（首页/商品/购物车/结算/订单/优惠券）    │
│   ├─ merchant/  商家中心（商品/订单/统计/留言/店铺设计）        │
│   ├─ eshop/     管理后台（用户/订单/退款/营销/通知）            │
│   ├─ system/    系统管理（RBAC：用户/角色/菜单/字典/租户）      │
│   └─ member~profile/  个人中心/资料/收藏/地址                  │
└──────────────────────────┬──────────────────────────────────┘
                           │ REST API（/api/**，JSON）
┌──────────────────────────▼──────────────────────────────────┐
│  后端应用层（Spring Boot 单体）                               │
│  Security(JWT 过滤器) → Controller → Service(@Transactional)  │
│       → Mapper(MyBatis-Plus) / Repository(ES)                │
│  AOP：LogAspect(操作日志) ｜ Interceptor：VisitLogInterceptor  │
│  定时任务：@Scheduled（自动取消订单/SKU同步/秒杀状态机）         │
└──────┬───────────────────────┬──────────────────┬───────────┘
       ▼                       ▼                  ▼
   MySQL 8（eshops，34表）   Redis 7（缓存/验证码/在线用户）  Elasticsearch（商品搜索，可选）
        └────────────── 本地文件存储 /uploads（图片）──────────┘
```

### 1.2 数据流与核心链路

- **认证**：登录 → 签发 JWT（Bearer）→ `JwtAuthenticationFilter` 解析 → `SecurityContextHolder` → 各接口鉴权
- **搜索**：商品写入 MySQL → `ProductSyncService` 同步到 ES → `ProductSearchController` 高亮搜索
- **实时推送**：`SseController`（/api/v1/sse/**）SSE 推送在线人数、字典同步
- **秒杀**：Redis 预减库存做并发闸门 → DB 扣减 → 场次状态机（预热/撤销）
- **AI 客服（旁路服务）**：前端 `/ai/chat`（Vite 代理）→ Python FastAPI :5000 → 通义千问（Function Calling Agent 循环）→ 主动调用后端公开接口（`/api/product/**` GET、`/api/seckill/sessions`）取真实数据 → 组织回答返回前端。前端零 token 传递，后端 Java 零改动。

## 4. 数据库结构（MySQL：eshops，34 表）

| 业务域 | 表 |
|--------|----|
| 用户与店铺（4） | `user`、`address`、`merchant_apply`、`store_design` |
| 商品（8） | `category`、`product`、`product_spec`、`product_sku`、`product_size_chart`、`product_image`、`product_comment`、`favorite` |
| 订单与购物车（4） | `cart`、`order`、`order_shipment`、`order_item` |
| 营销（8） | `coupon`、`user_coupon`、`seckill_session`、`promotion_activity`、`festival_coupon_plan`、`user_activity_record`、`user_signin_record`、`user_signin_reward` |
| 退款与支付（5） | `refund_application`、`refund_reason_category`、`refund_progress_log`、`refund_satisfaction`、`payment_record` |
| 通知与日志（5） | `sys_notice`、`sys_notice_read`、`merchant_message`、`operation_log`、`visit_log` |

> 设计约定：无物理外键（应用层维护关联）、核心表逻辑删除（`deleted`）、JSON 字段存规格/活动配置、订单快照、一单多商家（order → shipment → item）。详细字段见《数据库设计文档.md》。
