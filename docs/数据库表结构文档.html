约定说明（依据建表语句归纳，非臆测） ：

约定 依据
金额统一 decimal(10,2) （元，两位小数） 订单金额、退款金额、优惠券面值、拼团价、秒杀价等均为 decimal(10,2)。
时间多用 datetime ， create_time/update_time 成对出现且 update_time 自动更新 绝大多数表都有 create_time datetime DEFAULT CURRENT_TIMESTAMP 、 update_time ... ON UPDATE CURRENT_TIMESTAMP ；签到按天用 date （sign_date）。
user_id 普遍关联 user 表主键 address、favorite、order、payment_transaction、refund_application、merchant_message 等都有 user_id 且注释标明"用户ID"。
逻辑删除用 deleted （tinyint，0 正常 / 1 已删） user、product、category、order、group_buy_*、marketing_* 等均含 deleted 字段。
状态/类型字段用 tinyint ，取值以列注释为准 如 order.pay_status、product.status、seckill_session.status 等，注释里都写明了各取值含义。
高并发库存单独建字段做原子扣减 group_buy_activity.total_stock 注释"拼团可售库存（原子扣减）"、seckill_session.seckill_stock"秒杀独立库存"。
可空性以字段定义为准 表中"可空"列：否 = NOT NULL，是 = 允许 NULL。
