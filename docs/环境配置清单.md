## 3. 安装步骤

### 3.1 JDK 17（必须第一个装）

1. 下载 Temurin JDK 17（`.msi` 安装包）
2. 默认安装到 `C:\Program Files\Eclipse Adoptium\jdk-17.0.x`
3. **设置环境变量**（系统变量）：
   - `JAVA_HOME` = `C:\Program Files\Eclipse Adoptium\jdk-17.0.x`
   - `Path` 添加：`%JAVA_HOME%\bin`
4. 验证：
   ```powershell
   java -version
   # 应显示 openjdk version "17.0.x"
   ```

### 3.2 Git

1. 安装 Git for Windows（默认选项即可）
2. 恢复 SSH key（**重装前已备份到 `D:\backup\配置\.ssh`**）：
   ```powershell
   # 把 .ssh 文件夹恢复到用户目录
   Copy-Item "D:\backup\配置\.ssh" "C:\Users\admin\" -Recurse -Force
   # 验证
   ssh -T git@github.com
   # 看到 "Hi xxx! You've successfully authenticated" 即成功
   ```
3. 恢复 git 全局配置：`D:\backup\配置\.gitconfig` 复制到 `C:\Users\admin\.gitconfig`

### 3.3 Node.js + pnpm

```powershell
# 1. 安装 Node 22 LTS（.msi 安装包）
# 2. 安装 pnpm
npm i -g pnpm
# 3. 验证
node -v   # v22.x
pnpm -v   # 9+
```

### 3.4 MySQL 8

1. 运行 MySQL Installer，选择 **Server only** 即可
2. 配置：
   - 端口：**3306**
   - 认证方式：MySQL Native Password（或默认）
   - root 密码：**123456**（与项目配置一致，见 `application-dev.yml`）
3. 安装完成后服务自动启动（服务名 `MySQL80`）

### 3.5 Redis（Windows 服务版）

1. 下载 `tporadowski/redis` 的 Windows 版本（zip）
2. 解压到 `C:\Redis`（或 D 盘）
3. 注册为 Windows 服务：
   ```powershell
   # 管理员 PowerShell，进入解压目录
   redis-server.exe --service-install redis.windows.conf --service-name Redis
   redis-server.exe --service-start --service-name Redis
   # 验证
   redis-cli ping   # 返回 PONG
   ```

### 3.6 Elasticsearch 8.11.0（可选）

1. 下载 zip 解压到 `D:\elasticsearch-8.11.0`
2. 运行（**需要 JDK 17 环境**）：
   ```powershell
   cd D:\elasticsearch-8.11.0\bin
   .\elasticsearch.bat
   ```
3. 验证：访问 `http://localhost:9200`
4. 如不需要搜索功能，可跳过。但后端启动时若 ES 未运行可能报错，建议安装。

### 3.7 IntelliJ IDEA

1. 安装 IntelliJ IDEA（Ultimate 或 Community）
2. 首次启动配置 JDK：`File → Project Structure → SDKs` 添加 JDK 17
3. 推荐插件：Lombok、MyBatisX、Spring Boot Assistant

## 4. 项目恢复步骤

### 4.1 恢复数据库

```powershell
# 重装前备份文件在 D:\backup\mysql_backup_20260801.sql
# 导入备份（包含 eshops 及全部数据库）
cmd /c "C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe" -uroot -p123456 < "D:\backup\mysql_backup_20260801.sql"

# 验证
mysql -uroot -p123456 -e "SHOW DATABASES;"
mysql -uroot -p123456 -e "USE eshops; SHOW TABLES;"   # 应显示 30+ 张表
```

> 如果只恢复了部分数据，也可以用项目里的 `sql/eshops.sql` 重建基础表结构。

### 4.2 恢复后端项目（D 盘未丢失）

后端项目在 `D:\idea_workspase\e-shop`，重装后直接打开：

```
IDEA → Open → 选择 D:\idea_workspase\e-shop\pom.xml → Open as Project
```

首次打开会下载 Maven 依赖（较慢，需要网络）。

### 4.3 恢复前端项目（从 GitHub 克隆）

```powershell
cd C:\Users\admin
git clone <你的Eshop仓库地址> Eshop
cd Eshop
pnpm install      # 安装依赖（较慢）
pnpm dev          # 启动开发服务器 → http://localhost:3000
```


## 7. 常见问题

**Q1：后端启动报 "Access denied for user 'root'"**
- 检查 MySQL 服务是否启动：`Get-Service MySQL80`
- 检查 root 密码是否为 `123456`

**Q2：后端启动报 ES 连接失败**
- 启动 ES 或暂时注释掉 `application.yml` 中的 elasticsearch 配置

**Q3：前端 `pnpm install` 报错**
- 确认 Node ≥ 22.12：`node -v`
- 确认使用 pnpm 而非 npm：`pnpm -v`
- 删除 `node_modules` 和 `pnpm-lock.yaml` 后重试

**Q4：前端接口 404**
- 确认后端已启动（8080）
- 确认前端代理配置正确

**Q5：图片上传后不显示**
- 确认项目运行目录下存在 `uploads` 文件夹且后端有写入权限
- 图片路径以 `/uploads/...` 存储，由后端静态资源映射
